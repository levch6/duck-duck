# Duck Desk

A lab work web page that shows and explains ten common UI elements, themed as a rubber duck debugging rental desk.

Elements: radiobutton, checkbox, text input, tabs, button, text label, link, tooltip, dropdown list and data grid.

Built with HTML and CSS only.

## Run

Open `index.html` in a modern browser or visit the [website](https://levch6.github.io/duck-duck/).
