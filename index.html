Rubber duck debugging, now with a front desk

Duck Desk

Explain your bug to a duck. Feel slightly silly. Fix the bug. This page tours ten UI elements, and each one is a working part of the desk.

1

Radiobutton

Duck size

What it's for: picking exactly one option from a small set. Choosing a new option clears the previous one.

Use it when: all options should stay visible and only one can be true. A duck cannot be two sizes.

2

Checkbox

Duck extras

What it's for: turning independent options on or off. Any number can be selected, including none.

Use it when: choices do not exclude each other. A duck can absolutely wear all three.

3

Text input

A duck with no name is just a bath accessory. Splendid. The duck pretends to care. Ducks cannot read digits. Letters only, please.

What it's for: letting the user type free-form text on a single line, such as a name, an email or a search query.

Use it when: the possible answers cannot be listed in advance. Type a valid name and the nameplate at the top updates.

4

Tabs

Do not feed the duck. It is rubber. It has never once been hungry, and it will not thank you for the crumbs in your keyboard.
Weekly, in warm water. Squeeze gently afterwards, or the duck will whistle sadly through your next stand-up.
Go line by line and say what the code really does. The duck never interrupts, which puts it ahead of most code reviews.

What it's for: splitting related content into panels that share one space, with one panel visible at a time.

Use it when: people need one section at a time and do not have to compare them side by side.

5

Button

No squeaks yet. Suspiciously quiet. The duck has been squeaked. SQUEAK!

What it's for: starting an action right now, such as saving, sending or, in this case, squeaking.

Use it when: a click should do something. Reset restores every control on this page. Refund is disabled, because ducks keep the crumbs.

6

Text label

Click the words "Bug ticket number" and the cursor jumps into the field.

What it's for: static text that names or describes something. The user reads it but cannot edit it.

Use it when: a control needs a visible name. A linked label also gives a bigger click target and helps screen readers.

7

Link

  • Read about rubber duck debugging (opens in a new tab)
  • Jump to the duck roster (same page)

What it's for: taking the user somewhere else: another site, another page or another spot on this one.

Use it when: the result is navigation. If the click performs an action instead, it should be a button.

8

Tooltip

Two ducks, one bug. Whichever stares longer gets the credit.

What it's for: a short hint that appears on hover or keyboard focus and disappears afterwards.

Use it when: the extra detail is helpful but not essential. Never hide required instructions in one.

9

Dropdown list

"You've got this. Probably a missing semicolon." "You named that variable what?" "Wake me when the tests pass." "IS THAT PRODUCTION?!"

What it's for: choosing one value from a list that stays collapsed until it is opened, which saves space.

Use it when: there are too many options for radiobuttons, or the choice is not important enough to keep on screen.
